# Ссылки на приложения

Начиная с 0.6.2 карточки приложений автоматически ищут локальную HTTP-панель. Используются env/аргументы службы, README установленного пакета и TCP-сокеты его процесса либо дочерних процессов. Общего поля URL в YAM 0.2.5 нет. Порты чужих процессов не проверяются, диапазоны портов и локальная сеть не сканируются.

Автоматическая ссылка активируется только после HTTP-ответа с HTML на принадлежащем приложению порту. Ответы 404/5xx, JSON API и RTSP не считаются веб-панелью. 401/403 с HTML допустимы как экран авторизации. Доступность обновляется в фоне примерно раз в пять секунд при открытой панели. Это проверка со стороны колонки: межклиентская изоляция Wi-Fi или firewall могут мешать подключению с телефона.

Адрес строится из имени/IP, по которому открыта сама панель, обнаруженного порта и пути. Используй прямой LAN-адрес колонки; при доступе через обратный прокси нужен отдельный маршрут для панели приложения. Автопоиск поддерживает HTTP и IPv4, порты 1024–65535. HTTPS-only, IPv6-only и привязка только к localhost автоматически не публикуются. У приложений без веб-интерфейса ссылки нет. Пакет может иметь несколько HTTP-служб: выбирается первая подтверждённая панель, остальные можно указать вручную.

В «Описание и веб-интерфейс» доступны режимы «Определять автоматически», «Указать вручную» и «Не показывать». Ранее сохранённые порты остаются ручными. В ручном режиме HTML не требуется (можно открыть API), но 404/5xx не активируют кнопку. «Обновить» сбрасывает кэш; результат появляется при следующем фоновом обновлении.

Профили UwU Eyes и Now Playing Ticker задают подсказки 1213/1214. Они не активируют ссылку, пока соответствующий процесс не слушает этот порт. UWU_PORT имеет приоритет над подсказкой UwU. AirPlay 7000 — RTSP; он не становится ссылкой на сайт.

Сканер не запускает бинарники приложений, не изменяет службы или маршрутизацию и не отправляет токены YAM в браузер. Само приложение по своему адресу может требовать отдельный пароль.
