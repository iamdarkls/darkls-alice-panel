# DARKLS Alice Panel 0.1.2

Локальная панель для Яндекс Станции Мини 3 Про: собственная главная страница DARKLS,
прямое управление YAM и встроенные разделы dimap 0.1.4 в одном документе. Это форк с интеграцией, а не
независимая реализация всех инструментов dimap. MIT-лицензия и авторство dimap сохранены.

## Быстрый запуск на компьютере DARKLS

1. Остановите старую панель dimap, чтобы её монитор не разрывал ADB-соединение.
2. Распакуйте архив в отдельную папку `Downloads\darkls-alice-panel`.
3. Откройте `start.bat`. Оставьте окно открытым, пока пользуетесь панелью.
4. Откройте http://127.0.0.1:8770/ . Все разделы переключаются внутри DARKLS, например `/#player`.

По умолчанию: колонка `192.168.50.168:5555`, профиль `mini3pro`, HTTP-порт `8770`.
Запуск не устанавливает и не переустанавливает YAM. Используется уже работающий yamd на порту 8099.
На компьютере нужны Python (работающий `py`) и Android platform-tools.
Launcher ищет ADB в `Downloads\platform-tools`, а FFmpeg — в прежней папке dimap.
Оставлять старый сервер включённым для этого не нужно.

Запуск из PowerShell:

```powershell
cd "$env:USERPROFILE\Downloads\darkls-alice-panel"
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-darkls.ps1
```

Другой IP/порт:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\start-darkls.ps1 -Device 192.168.50.168:5555 -Port 8770
```

Прямой запуск, включая отдельный адрес YAM:

```powershell
$env:ADB = "$env:USERPROFILE\Downloads\platform-tools\adb.exe"
py -3 -u .\darkls.py --device 192.168.50.168:5555 --model mini3pro --yam-url http://192.168.50.168:8099 --open
```

Python 3.13 достаточен для основной работы. Для обработки zstd-анимаций исходной
студии нужен Python 3.14 или утилита zstd. FFmpeg нужен для аудио, кроме WAV.
HTTPS по умолчанию выключен; его можно включить аргументом `--https-port 8771`, если
установлен OpenSSL. Для доступа с другого устройства запускайте с `--host 0.0.0.0`.
Пароль задаётся в студии → Настройки → Доступ; он общий для главной и студии.
Панель рассчитана на доверенную локальную сеть. Порты панели, YAM и ADB не следует
пробрасывать в интернет: сама панель не добавляет пароль на порт YAM 8099.

## Возможности

| Раздел | Реализация |
| --- | --- |
| Главная DARKLS | Отдельные статусы YAM/ADB, профиль устройства, датчики, быстрые переходы |
| Пакеты YAM | Список, загрузка локального .yap, реестр yapkg, SHA-256 при установке из реестра |
| Управление пакетами | Запуск, остановка, включение, удаление, автозапуск служб, логи |
| Настройки YAM | Разрешение бинарных пакетов с сохранением остальных полей настроек |
| Музыка | Исходный плеер dimap, очередь, тексты, похожие треки, QR-вход Яндекса и Glagol |
| Свет и часы | Исходные инструменты dimap и профиль Pickle |
| Файлы и терминал | Просмотр, редактор, загрузка/скачивание, интерактивная root-консоль xterm |
| Bluetooth | Исходное управление сопряжениями в студии |
| Метрики и логи | Графики, CSV, события и логи Quasar/dmesg |
| Доступ | Общий пароль, сессии, опциональный HTTPS |
| Будильники и заставка | Исходный код сохранён; доступны только профилям, которые поддерживает dimap |

**Ограничения Mini 3 Pro сохранены:** dimap помечает пользовательский будильник,
замену заставки/звука запуска и некоторые операции восстановления как неподдерживаемые.
Эти пункты не включены принудительно. Наличие кода не означает совместимость с Pickle.
Для функций плеера может потребоваться вход в Яндекс в настройках студии.
Основной сценарий этой версии — одна колонка; исходный multi.py сохранён, но не
интегрирован с новой главной DARKLS.

В версии 0.1.2 убраны переходы в отдельную студию: плеер, файлы, терминал, графики,
логи, настройки, приложения, будильники и запуск встроены в единую страницу DARKLS.
Используются один DOM, одно меню и один маршрутизатор; iframe не используется.
Адрес `/studio` оставлен только для совместимости и отдаёт ту же объединённую страницу.

Главная и пакеты YAM продолжают работать при недоступном ADB. Студия dimap для
большинства функций требует ADB; это честно показывается отдельным статусом.
Новая главная запрашивает датчики из API YAM, не подставляет демонстрационные данные.

## Что исправлено и изменено

- Исправлена нормализация `\r\r\n` из старого сетевого adbd на Windows: профиль
  больше не теряет маркеры начала и завершения удалённой команды.
- Проверка соединения устанавливается после профиля модели, который переопределяет
  `_alive()`. Результат `id` проверяется в реальном shell, ошибки видны в журнале.
- Убраны дополнительные TCP-пробы порта adbd и частый цикл переподключения.
  Повторная проверка и задержки уменьшают лишние разрывы соединения.
- YAM использует прямой HTTP к колонке и официальный путь `/data/quazar/yam`.
- Управление существующим автозапуском YAM работает с `/etc/init.d/S99yam`.
  Новый хук Lite 2 не устанавливается на Mini 3 Pro.
- Обновление бинарника YAM из студии сохраняет предыдущий бинарник в
  `/data/quazar/yam/backups`; данные пакетов не удаляются. Это не полный бэкап
  данных и не автоматический откат при ошибке обновления.
- Обновление панели поверх DARKLS чужим релизом dimap отключено: обновлять форк
  нужно отдельной сборкой. Репозиторий и commit основы указаны в UPSTREAM.json.
- Запуск в отдельной папке и на порту 8770 не перезаписывает старую панель.

## Проверка сборки

```sh
python -m unittest discover -s tests -v
python -m compileall -q .
node --check static/darkls.js
```

Контрактные тесты используют локальный имитатор yamd и не обращаются к колонке.
Проверены: ответы API, YAM при отключённом ADB, переносы CRCRLF, удалённые коды
завершения shell, действия над пакетами, multipart-загрузка, сохранение настроек,
проверка пароля/Origin и ограничения профиля.

Сборка проверена локально. Физическая Mini 3 Pro и запуск на Windows из этой среды
недоступны; проверку на устройстве нужно выполнить после распаковки у владельца.

Сборка unified.html: `python tools/build_unified.py`. Источники шаблонов сохранены
в static/index.html и static/darkls-native.html. После изменения шаблонов нужно пересобрать
единый документ. Проверены переходы между встроенными разделами в DOM-тесте.

В 0.1.2 восстановлены исходные меню, карточки, отступы, цвета и светлая/тёмная
темы dimap. Стиль DARKLS больше не перекрывает оформление исходных инструментов.
При доступном ADB стартовая вкладка — привычный «Обзор» dimap; без ADB доступна
главная со статусами YAM и независимым управлением пакетами.
