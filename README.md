# DARKLS Alice Panel 0.6.3

Автономная панель для rooted Яндекс Станции Мини 3 Про (pickle, aarch64). Работает на колонке в /data/darkls-alice; после установки ПК и ADB для работы панели не нужны. Основа интерфейса: dimap/yandex-station-web, MIT.

## Обновить установленную панель

Открой http://192.168.50.168:8770 → «Обновления панели» → «Проверить» → «Установить обновление». После перезапуска обнови страницу (Ctrl+F5 на ПК). Не запускай первоначальную установку повторно.

Источник:

```text
https://github.com/iamdarkls/darkls-alice-panel/releases/latest/download/update.json
```

GitHub Actions запускает тесты, собирает пакет и публикует новый номер версии из app/DARKLS_VERSION. Уже выпущенные версии не перезаписываются. Панель проверяет HTTPS, репозиторий, размер и SHA-256; отдельной криптографической подписи релизов панели нет. При неудачном запуске установленный supervisor возвращает предыдущую сборку. Автоустановка включается отдельно в интерфейсе; данные, runtime, firmware и supervisor при обычном обновлении не заменяются.

## Актуальный YAM v2

Открой «YAM v2» → «Установить актуальный YAM» → «Подключить официальный реестр». На момент выпуска проверена версия 0.2.5. CLI устанавливается отдельно в /data/yam; обновление панели само не запускает установку менеджера.

Поддержаны поиск, описание пакета, план зависимостей, установка из реестра и загрузка .yampkg, удаление, файлы, поиск владельца, реестры с Ed25519, doctor/repair, Entware и декларации служб. Обновление самого YAM использует его штатную проверку подписи. Подробности, пути и ограничения: [YAM-V2.md](YAM-V2.md).

## UwU Eyes 1.11.4

Исправлен запуск vegych/uwu-eyes-panel, ожидающего YAM_API_URL/YAM_API_TOKEN. Для него хост предоставляет ограниченный локальный API сегментного экрана с отдельным токеном. После обновления перезапусти службу; детали контракта и аппаратной проверки — [UWU-COMPAT.md](UWU-COMPAT.md). Это не общий runtime для любых плагинов.

## Приложения и автозапуск

Новый раздел «Приложения» показывает карточки пакетов, службы, журналы и настраиваемые описание/веб-интерфейс. Службы запускает собственный хост панели: запуск, остановка, перезапуск, автозапуск после загрузки и проверка восстановления. ПК, браузер и yamd для автозапуска не нужны. Автозапуск выключен по умолчанию; до 8 служб одновременно. Перед изменением пакетов через панель хост приостанавливает процессы. Поддерживаемые декларации, зависимости, задержки после ошибок и пути данных описаны в [APP-HOST.md](APP-HOST.md).

## Завершить переход с yamd

После обновления панели открой «YAM v2». Если CLI ещё не установлен, нажми «Установить актуальный YAM», затем «Завершить переход и убрать yamd». Панель проверит запуск нового CLI, сохранит S99yam и прежний флаг автозапуска, отключит их, остановит процессы прежнего runtime и перенесёт весь /data/quazar/yam в приватный архив /data/darkls-alice/archives/yamd-…/runtime. Данные не удаляются и занимают прежнее место на flash. Путь архива и состояние сохраняются в data/yamd-retirement.json. Неизвестный загрузочный скрипт или символьные ссылки автоматически не изменяются. При ошибке переноcа пути и автозапуск восстанавливаются; если старые процессы уже остановлены, самостоятельно они в этом случае не запускаются.

Экранов Legacy и старого API пакетов в панели больше нет. Часы, свет, Bluetooth, музыка, файлы и консоль управляются напрямую. Сведения устройства и доступные датчики читаются локально из ядра; если датчик не опубликован в поддерживаемом sysfs-формате, панель сообщает об отсутствии данных. Диагностика не требует HTTP API на 8099. Консоль использует /data/yam/bin и профиль pickle.

Установленные .yap не преобразуются в .yampkg; их выполнение прекращается при завершении перехода. Запуск служб в самом YAM 0.2.5 не реализован; панель 0.6.0 добавляет собственный хост. Архив остаётся для ручного восстановления. Возврат версии панели сам по себе не возвращает архивный yamd.

## Аудиоформаты

«Настройки → Аудиоформаты → Установить аудио-FFmpeg». ARM64-сборка скачивается отдельно из Xiragi/FFmpeg-Audio-Builds; установщик проверяет хеш, архитектуру и реальную конвертацию на устройстве. Нужно 60 МБ свободно в /data и 90 МБ в /tmp на время установки. Сжатая копия хранится в /data, рабочий бинарник восстанавливается в /tmp после перезагрузки. Без FFmpeg поддерживается WAV.

## Остальные возможности

- Управление колонкой, плеер, файлы, root-консоль, графики и журналы с ограничениями профиля Mini 3 Pro.
- Резервные копии настроек для скачивания. Полный дамп NAND и приложения YAM в них не входят. Секреты включаются только отдельным переключателем: такой архив нужно хранить приватно.
- Диагностика прошивки, памяти, служб и связи. Отчёты скрывают токены.
- Вкладка ChatGPT управляет внешним голосовым агентом на Linux-сервере. Совместимость аудиомоста с Mini 3 Pro требует отдельной проверки и не предполагается установленной.

Не открывай root-панель и ADB в интернет. Вход в панель и защита POST от чужого Origin применяются и к API YAM v2.

## Проверки и сборка

```sh
python -m unittest discover -s tests -v
python -m compileall -q app
node --check app/static/native-yam2.js
python build-release.py --repository iamdarkls/darkls-alice-panel
```

DOM-тест: установи npm-пакет happy-dom и запусти `node tests/ui.mjs` (или укажи путь к модулю в HAPPY_DOM_MODULE). Для интеграционной проверки официального ARM-бинарника под QEMU см. YAM-V2.md. Физическая колонка проверяется отдельно после установки.
