Версия 0.6.1 — исправление запуска UwU Eyes 1.11.4

• Добавлен ограниченный локальный Runtime API для vegych/uwu-eyes-panel: проверенные методы GET /device и POST /clock. Возвращать старый yamd не требуется.
• Хост передаёт отдельный токен и loopback URL через YAM_API_TOKEN/YAM_API_URL. Пароль панели не используется; токен не выводится в статусе и отзывается при остановке службы.
• Поддержка сегментного экрана объявляется только при наличии доступных LED-узлов Mini 3 Pro. Кадры проверяются по списку сегментов и диапазону яркости, прежние значения и triggers восстанавливаются при освобождении экрана.
• В карточке службы появилась отметка «адаптер экрана». Для штатного завершения UwU Eyes выделяется до 10 секунд.

После обновления панели перезапусти службу UwU Eyes в «Приложениях». Веб-панель пакета по умолчанию доступна на порту 1213. Исправление проверено на моделируемом экране и тестовом процессе; анимацию на реальной колонке нужно проверить после установки. Загруженный бинарник исследован без запуска и не включён в релиз.
