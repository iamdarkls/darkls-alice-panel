Версия 0.6.0 — запуск приложений YAM и проверка восстановления

• Новый раздел «Приложения»: карточки установленных пакетов, версия, настраиваемое описание, состояние служб и ссылка на их HTTP-интерфейс при заданном порте.
• Добавлен собственный локальный хост служб: запуск, остановка, перезапуск, журнал и отдельный автозапуск. Legacy yamd не требуется.
• Поддерживаются exec/env, переменные YAM, restart never/on-failure/always, oneshot и ожидание зависимостей. Автозапуск по умолчанию выключен, до 8 служб одновременно, повторные сбои получают задержку.
• Хост запускается вместе с нативной панелью без браузера и ПК. Перед изменением пакетов через панель приложения приостанавливаются и затем возобновляются.
• Добавлена проверка восстановления: локальная панель, YAM CLI, выбранные службы, дата и понятный отчёт. Наличие процесса не означает полную готовность приложения.
• Журналы ограничены по размеру, API требует входа и проверяет Origin. Декларации читаются из базы YAM без её изменения.

После обновления открой «Приложения». Включи автозапуск только у нужных служб; для запуска сразу нажми «Запустить». Для веб-интерфейса укажи его фактический порт в карточке. Хост поддерживает службы на переднем плане; отдельного .yap-конвертера нет.
