DARKLS Alice Panel 0.6.2

Автоматические ссылки на веб-панели установленных приложений.
• Поиск по настройкам службы, README и TCP-портам процесса приложения.
• Кнопка активируется после ответа HTTP с HTML-интерфейсом. RTSP AirPlay не принимается за веб-панель.
• Режимы: автоматически, свой порт и путь, не показывать. Ручные настройки прежних версий сохраняются.
• Видны источник адреса и причина недоступности. Проверка идёт в фоне, без сканирования сети.
• UwU Eyes: автоматический профиль порта 1213 с учётом UWU_PORT.

После обновления службы без выбранного автозапуска может понадобиться запустить снова. IPv6-only и HTTPS-only интерфейсы автоматически не поддерживаются; сетевую доступность с телефона проверяет пользователь.
