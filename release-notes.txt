Версия 0.4.0 — поддержка актуального YAM v2

• Добавлен отдельный раздел YAM v2 с локальным CLI-адаптером для Мини 3 Про (pickle). Панель больше не требует старого HTTP API yamd для управления новыми пакетами.
• Актуальный YAM ARM64 устанавливается по кнопке в /data/yam после проверки SHA-256 и запуска бинарника. На момент выпуска актуален YAM 0.2.5.
• Поддержаны .yampkg: загрузка локального пакета, установка из подписанного реестра, план зависимостей, удаление, список файлов и поиск владельца.
• Добавлены подключение официального и собственных реестров с Ed25519, поиск и описание пакетов, doctor, repair, Entware и просмотр деклараций служб.
• Обновление YAM использует штатную проверку подписи менеджера; перед операцией сохраняется копия бинарника и базы.
• Прежний yamd, .yap и их данные остаются отдельно в Legacy. Конвертер .yap и запуск служб YAM v2 не реализованы в самом YAM 0.2.5; панель не обещает эти возможности.
• Обновление панели не устанавливает YAM автоматически: открой раздел YAM v2 и нажми «Установить актуальный YAM».
