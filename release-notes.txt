Версия 0.3.1

• Исправлено обновление yamd: релизы нового YAM CLI yam-v0.2.x больше не принимаются за обновление старого демона. Для установленного yamd выбирается совместимая ветка v0.1.x.
• Обновление yamd проверяет SHA-256 и запуск нового бинарника до остановки старого, сохраняет копию данных и возвращает предыдущий бинарник при ошибке.
• В Настройки → Аудиоформаты добавлена установка аудио-FFmpeg ARM64. Совместимость и конвертация проверяются на колонке до применения.
• FFmpeg хранится сжатым в /data, рабочая копия находится в /tmp и восстанавливается после перезагрузки без ПК. Аудиоинструмент устанавливается отдельно по кнопке.
• Сообщения о форматах теперь объясняют, где включить поддержку MP3, M4A/AAC, FLAC и OGG.
• Добавлена сборка и публикация обновлений панели через GitHub Actions. Манифест формируется как обычный JSON без метаданных PowerShell.
