# Интерфейс Vue 3 (0.7.0)

Интерфейс собирается Vue 3 + TypeScript + Vite. На колонке работают Python и готовые статические JS/CSS; Node, npm и исходники frontend на колонку не устанавливаются. URL и Python API сохранены, включая /speaker/ID/ и отдельный контекст устройств.

## Структура

- `frontend/src/App.vue`: постоянная структура страниц и реактивное переключение hash-вкладок. Все страницы смонтированы единожды: ввод в формах и виджеты не теряются при навигации.
- `frontend/src/pages`: отдельные SFC всех 16 вкладок плюс экран соединения. Приложения, YAM, обновления, диагностика, копии, ChatGPT и главная используют Vue refs, computed, v-model и события.
- `frontend/src/components`: меню, иконки, статус проверки, вход, аудиоинструменты и нижний плеер.
- `frontend/src/composables`: запросы с контекстом колонки/таймаутами, реактивная навигация, подписки и lifecycle.
- `frontend/src/device/controls.js`: адаптер проверенных команд устройства и сложных DOM-виджетов (плеер, SVG-редакторы, графики, файлы, xterm). Он запускается из Vue composable один раз; таймеры, обработчики и терминал освобождаются при размонтировании приложения. Эти виджеты сохраняют своё состояние и DOM; их внутренние отрисовщики остаются императивными, а не переписываются искусственно на шаблоны Vue.
- `app/static/model.js`, Three.js и xterm остаются локальными специализированными библиотеками, инициализируемыми после монтирования DOM. Отдельной старой HTML-панели и параллельных контроллеров native-*.js больше нет.

## Сборка

Требуется Node 24 и npm. Из корня репозитория:

```sh
npm ci --prefix frontend
npm run build --prefix frontend
python build-release.py --repository iamdarkls/darkls-alice-panel
```

Версии и integrity зависимостей закреплены package-lock.json. TypeScript 6.0.3 выбран из-за несовместимости vue-tsc 3.3.14 с новым пакетом TypeScript 7 (не экспортируется lib/tsc). Проверка типов обязательна до Vite build.

Результат — `app/static/ui/panel.js`, `panel.css` и `source.sha256`. fingerprint включает все исходники и настройки сборки; build-release.py откажется упаковать устаревший bundle. node_modules не попадает в исходный ZIP или app.tar.gz.

## Проверки

GitHub собирает интерфейс, проверяет типы, запускает браузерный тест через установленный Chrome runner, затем тесты Python и публикацию. Для локального браузерного теста:

```sh
BROWSER_EXECUTABLE=/path/to/chrome node tests/ui.mjs
```

Тест использует локальный сервер и фиксированные ответы API, проверяет вкладки, действия, сохранение форм, темы, размеры 320/390/1360, выбор колонки и вход. Он не выполняет команды на реальной колонке. Аппаратную проверку звука, LED, терминала и 3D на устройстве проводит владелец после обновления. Возврат к предыдущей версии доступен прежним механизмом панели.

При переносе выполнено сравнение скриншотов десяти разделов с 0.6.5 на одинаковых ответах API. Высоты страниц и карточек совпали, включая главную, приложения, YAM, обзор и настройки. Динамические данные и номер версии могут различаться.
