DARKLS Alice Panel 0.8.0

- Сценарии запускаются вручную, по расписанию и по своей фразе. Действия включают громкость, цвет кольца, паузу и текстовую команду Алисе. В редакторе можно добавить ветку для выходных.
- Экспериментальная вкладка обучения своих слов активации с выбором действия для каждой фразы.
- Экспериментальный голосовой помощник на колонке для OpenAI-совместимых API. Включается вручную.
- На телефоне появились нижняя навигация, жесты на обложке плеера и дополнительные клавиши терминала.
- Исправлены проверочный запуск будильника, обработка монофонического микшера и задержка повторного звонка. Остановка будильника завершает только его проигрыватель.
- Ошибки Bluetooth теперь видны в панели.
