DARKLS Alice Panel 0.7.0

Интерфейс перенесён на Vue 3 + TypeScript + Vite с сохранением текущей разметки, цветов, тем, иконок и адаптивного оформления.

Все 16 вкладок разделены на компоненты. Навигация, главная, управление приложениями, YAM, обновления, диагностика, резервные копии, ChatGPT и вход используют состояние и события Vue. Ввод в формах сохраняется при переходах. Специализированные виджеты устройства, плеер, SVG-редакторы, терминал и 3D подключены через адаптеры к постоянным Vue-компонентам.

Vue поставляется локально в собранном JS/CSS. Node.js нужен только для сборки в GitHub и не устанавливается на колонку. Python-сервер, API, автозапуск и механизм отката сохраняются. Проверяются типы и соответствие bundle исходникам. Удалены прежние параллельные контроллеры native-*.js.

После установки обнови страницу. Для аппаратных функций требуется проверка на своей колонке.
